# blackout

- After every meaningful change, run `bun run check` then `bun run deploy` so the latest build is live at https://anoma.ly/labs/blackout/.
- WebGPU only runs in secure contexts: test via the deployed URL, the opentunnel dev URL or `localhost`, never a bare LAN hostname.
- `TUNNEL=1 bun run dev` runs Wrangler (rooms, :8788) and Vite (:5191); opentunnel route `blackout` exposes it at https://blackout.lwoyjcaeyxv6.opentunnel.xyz.
- The game is a plain top-down shooter: everyone sees everyone, three guns (rifle, shotgun, sniper), health with regen, respawns, a new procedural office floor every match. No progression, no bots online (only the dev `?practice` mode has bots; `?practice&mode=dom` picks a mode).
- Modes (`shared/sim/modes.ts`, placements from the map in `shared/sim/places.ts`): free for all, team deathmatch, domination, search and destroy. Create game picks the first mode (`?mode=` on the first socket); quick rooms start as FFA; the end screen votes on the next.
- Kill confirmed, hardpoint and capture the flag live in `shared/sim/modes-objective.ts` (zones and flag bases from `places.ts`; sprites in `src/game/objective-fx.ts`). Modes in other files register in `MODE_FACTORIES` (modes.ts can't import them: cycle) and World imports the file. The end screen offers the current mode plus three random others (`voteOptions`, world rng, sent in the snapshot); per-mode scoreboard counts go in `Player.stats`.
- Infected, gun game and one in the chamber live in `shared/sim/modes-rules.ts`. What a player fights with comes from `Mode.loadout()` as a `Kit` (`shared/sim/kit.ts`: gun or bare hands, mag, reload, damage, speeds, melee, equipment); the World and client prediction (`src/game/game.ts`) read only the kit. Melee (`shared/sim/melee.ts`): the combat knife on right click or V in every mode (every gun kit has it; drawn in the left hand mid-swing), or the trigger when bare-handed; 0.15 s wind-up, one-hit kill within 1.5 m.
- Zombie modes (co-op waves) live in `shared/sim/modes-zombie.ts`: zombie survival (`zsv`, ten waves, the fallen get up when a wave is cleared), endless night (`zend`) and hold the line (`zhold`, the horde eats a zone's integrity). Zombies are players the mode runs (`Player.npc` = their kind, `World.addNpc`, `ZombieBrain`): team 1, not on the roster, not seats for `fill()`, purged when the match ends; the snapshot tags them `z`. A kit's `swing` makes melee hurt instead of kill. Kinds, wave sizes and pacing are the `ZOMBIES`, `ZOMBIE`, `HOLD` and `TUNING` tables; the client side is `src/game/zombie-fx.ts`, `rules-fx.ts` and `src/ui/rules-hud.ts`. Practice gives you one bot ally (`?practice&mode=zsv`).
- Sprinting: hold Shift, or double-tap any movement key (WASD or arrows) and keep moving. Stamina (`shared/sim/stamina.ts`) drains while sprinting and refills after a pause; run it dry and you're winded (a short cool-off, then no sprint until it's back to a third). The server enforces it and client prediction replays it from `you.stamina`. Q holds the far look-ahead (right click used to).
- Zombie bodies are their own meshes (`src/render/zombie.ts`: walker/runner and brute) on the soldier's rig, posed hunched and reaching in `src/game/anim.ts` (`Avatar.zombie`). `anim.html?only=z1,z2,z3,k` shows the dead and a knife swing.
- Self-hosted (Docker/Kubernetes): `server/bun.ts` (`bun run start`) serves the built client and runs the same `RoomCore` (`server/room-core.ts`) and `Matchmaker` in one process; one replica only, rooms are in memory. The `Dockerfile` builds it; `.github/workflows/deploy.yml` checks, pushes `ghcr.io/enderdincer/zombieland:sha-…` on master and opens the bump PR in `enderdincer/homelab-k8s-manifests` (`manifests/tools/zombieland`, https://zombieland.defterlab.com). Cloudflare (`bun run deploy`) still works alongside.
- The simulation in `shared/` runs on the Durable Object and in the browser (practice mode, prediction); keep it free of DOM and Worker APIs.
- Target look: `concept/look-1-office.png`. Screenshots: apollo's Chrome via browser-control (call `page.bringToFront()` first or rAF is throttled to 1 fps), or `bun scripts/shot.ts` (local headless SwiftShader).
- Room host (`shared/sim/host.ts`, ♛ on the scoreboard): picks teams in team modes, and in any mode restarts the match (`hostRestart` → `World.restart`: reset or switch mode, new floor by default, 3 s cooldown, a `host` event for the banner) from the HOST panel in the Tab/T scoreboard (two clicks to confirm).
- Idle kick (`server/room.ts` RoomCore): 90 s with no input while alive in play gets you kicked (end screen and time dead don't count), with a 15 s `idle` countdown shown in the HUD status line.
- Client/server version: `scripts/build-id.ts` hashes `shared/` into `shared/build.gen.ts` (gitignored; check, test, build, deploy and dev generate it). The client sends it in `hello`; a server with a different hash replies `reload` and the client reloads into the same room (old clients without a build get an error asking them to reload).
